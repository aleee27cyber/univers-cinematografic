# Univers Cinematogràfic de Superherois

Aquest projecte recull la creació d'un univers cinematogràfic de superherois inspirat en pel·lícules com Avengers, Spider-Man, Iron Man o Black Panther.

El repositori inclou l'índex de la saga, els capítols amb la història de l'univers, les fitxes dels superherois i vilans, i les pel·lícules amb els seus arguments. Tot el treball es gestiona amb Git en local, de manera que cada canvi important queda registrat en un commit.
